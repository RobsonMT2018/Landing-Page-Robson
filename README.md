# 🚀 Landing Page Portfolio - Robson Maciel (.DEV)

Uma landing page moderna, ultra-rápida, responsiva e com design dark elegante desenvolvida para apresentar meus serviços de **Desenvolvimento Web & Landing Pages de Alta Conversão**.

O projeto conta com animações fluidas via CSS/Intersection Observer, uma **vitrine interativa de projetos** com alternância de miniaturas e chamadas para ação (CTA) diretas para o WhatsApp.

---

## ✨ Destaques do Projeto

* **🎨 Design Dark & Moderno:** Interface escura refinada com efeitos de brilho em neon (cyan/green) e tipografia limpa com a fonte *Plus Jakarta Sans*.
* **🖼️ Vitrine Interativa de Projetos:** Sistema em JavaScript que permite ao usuário navegar entre diferentes cases de sucesso diretamente na tela principal através de thumbnails interativas.
* **📱 100% Responsivo:** Adaptado com precisão para dispositivos móveis, tablets e telas de alta resolução.
* **⚡ Alta Performance:** Feito em HTML, CSS e JS nativos (sem frameworks pesados), garantindo um carregamento instantâneo.
* **🎯 Foco em Conversão (CRO):** Botões estratégicos com links diretos para atendimento e orçamentos via WhatsApp.
* **✨ Animações de Revelação (Scroll Reveal):** Efeito suave de entrada das seções conforme o usuário navega na página.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5 Semântico:** Estruturação focada em SEO e acessibilidade.
* **CSS3 Moderno:**
  * Variáveis CSS (*Custom Properties*) para rápida manutenção de cores.
  * Flexbox e CSS Grid para layouts limpos.
  * Animações, transições e *glassmorphism* (efeito acrílico).
* **JavaScript Vanilla (ES6+):**
  * Lógica interativa do palco/galeria de projetos.
  * *Intersection Observer API* para o efeito de animação ao rolar a página.
  * Atualização dinâmica do ano do copyright no rodapé.
* **Google Fonts:** Tipografia *Plus Jakarta Sans*.

## 🌐 Como Publicar no GitHub Pages

1. **Renomeie o arquivo principal:**
   * Certifique-se de que o arquivo HTML principal esteja nomeado como **`index.html`** na raiz do repositório.

2. **Suba os arquivos para o GitHub:**
   * Envie o arquivo `index.html`, o `README.md` e as imagens de demonstração (`projeto1.png`, `projeto2.png`, etc.).

3. **Ative o GitHub Pages:**
   * Vá até as **Settings** (Configurações) do repositório no GitHub.
   * No menu lateral, clique em **Pages**.
   * Em **Branch**, selecione `main` (ou `master`) na pasta `/ (root)`.
   * Clique em **Save**.
   * Aguarde alguns instantes e o seu portfólio estará online!
